```
0x24df9a  mov  r14, qword ptr [rbp - 0x68]
0x24df9e  cmp  dword ptr [r14 + 0x220], edx
```

attribution is `may`, and it is the first time this site has an object at all.

## Negative controls

Three new fixtures, each asserting the *refusal*, plus the S1.6/S1.7 set:

* `callee_may_two_objects` — two different fields reach the same release through a loop header ⇒
  the may-set holds two objects ⇒ **no attribution** (this fixture failed twice: once because a
  state copy shared its may-set, once because an early traversal's single candidate was never
  retracted);
* `callee_clobbered_by_call` — an indirect call in between ⇒ the argument register is clobbered ⇒
  **no attribution**;
* `callee_may_release_in_loop` — one object on the loop path, a non-object on entry ⇒ attributed
  **`may`, never `must`**.

The S1.6 hop controls are recomputed unchanged: 12 conditional transfers, 0 proved, 3 same-caller and
3 other-register edges `REFUTED`, verdict `SUPPORTED`.
