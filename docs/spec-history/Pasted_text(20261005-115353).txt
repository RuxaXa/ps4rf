ARCHITECTURE.md
PS4RF Architektur
Host vs Target

    Host (Research-PC): ps4rfctl, Experiment Engine, Discovery, Evidence,Profile, OrbisProbe, Tool-Adapter. Orchestrierung und Wahrheit.
    Target (PS4 / Mock): ps4rfd stellt AUSSCHLIESSLICH Primitive bereit(memory, gpuvm, keymgr, ccp, kernel.snapshot, sync, verify.*). KeineExperiment-Logik, keine Firmware-RVAs im Code — RVAs nur in Profilen.

Handshake-Rollen (normativ, unabhängig von TCP connect/accept)

AGENT (ps4rfd/Mock):  send HELLO → recv HELLO_ACK → send AUTH → recv AUTH_ACKHOST  (ps4rfctl):     recv HELLO → send HELLO_ACK → recv AUTH → send AUTH_ACK

HELLO = AGENT→HOST (agent_version, context, provider, boot_id, nonce).HELLO_ACK = HOST→AGENT (protocol_version, session_id, AEAD-Suite, Limits).Host entscheidet Limits; beide Seiten nutzen exakt das authentisiertehost_hello_ack["limits"]-Objekt (kein DEFAULT nach Handshake).

Transcript: SHA256(JCS(agent_hello) || JCS(host_hello_ack)).
RPC + AEAD

    Session Key (256 Bit) nur vom Bootstrap injiziert; nie URL/Log/Evidence.
    HKDF mit Transcript-Bindung; getrennte Richtungsschlüssel(k_agent_to_host/k_host_to_agent), Handshake-Key separat (k_hs).
    AEAD_CHACHA20_POLY1305 (Default) / AES_256_GCM. Nonce = 32-Bit-HKDF-Präfix|| 64-Bit-Sequence, ausschließlich lokal abgeleitet (Wire: nur seq+ct).
    AAD ausschließlich via build_aad(protocol_version, session_id, sequence, direction, message_type). Sequence 0..2^64-2, strikt; Duplicate/Skip/Rückwärts → REPLAY_DETECTED → Session-Abort.
    Framing: MAX_HANDSHAKE_BYTES (64 KiB) vor Read; max_frame_bytes =Ciphertext-Limit (Tag 16); Oversize-Reject verbraucht KEINE Sequence.

Capability-System: Availability × Assurance

    Availability: UNKNOWN/AVAILABLE/DEGRADED/UNAVAILABLE (Session-Wahrheit jetzt)
    Assurance: UNVERIFIED/OBSERVED/PROVEN (Belegqualität, verfällt nicht durchRecency). Auflösung unabhängig pro Achse.
    Authority-Tiers: RUNTIME_PROBE ∪ EXPLOIT = Tier 30 — neuester Session-Befundgewinnt, ausschließlich über host-vergebenes observed_seq(provider_created_at ist nie Conflict-Autorität). OPERATOR:availability_write=false; absoluter Override nur via ManualOverride(Assurance max OBSERVED).
    PROVEN: genau ein Erzeugungspfad — grant_from_verification() ausEvidence-Store-verifizierter VerificationEvidence; Authority-Ceilingentscheidet; privilegierte Namespaces (kernel., gpuvm., keymgr., ccp.,samu., pup., eap., sbram., emc., secure.) verlangenverification_run != trigger_run.
    Grant: context match ∧ availability==AVAILABLE (∧ DEGRADED && allow_degraded)∧ assurance ≥ Namespace-Minimum. PROVEN + UNAVAILABLE = NOT GRANTED(Beleg bleibt erhalten).

BOOT vs SESSION

    SESSION: an (session_id, boot_id) gebunden; observed_seq nur session-lokal.
    BOOT: an genau eine boot_id gebunden; überlebt keinen Reboot.expires_on_reboot=False für BOOT-Records ist verboten. Persistente Faktenleben im Profile/Evidence-Store und werden pro Boot NEU ingestiert.
    Merge (F4): SESSION-Availability in {AVAILABLE, DEGRADED, UNAVAILABLE} gewinnt;sonst BOOT. Assurance = max(BOOT, SESSION); Provenance bleibt erhalten.

Resource Lifecycle + RECOVERY_REQUIRED

    ResourceManager: acquire/attach_cleanup/release/cleanup_all/cleanup_after_hang,atomar (RLock). FREED nur nach tatsächlichem Callback-Erfolg.
    Normaler Disconnect → cleanup_all. Nach Hang → cleanup_after_hang: nurout_of_band_cleanup_safe=true wird angefasst; alles anderecleanup_attempted=False, UNCERTAIN, console_dirty=true.
    Poison (atomar): session_poisoned+console_recovery_pending sofort; keineneuen Submissions; queued → CANCELED_AT_RECOVERY (RID abgeschlossen, Responsebei intaktem Transport); in-flight → IN_FLIGHT_AT_RECOVERY in Evidence.
    RECOVERY_REQUIRED ist konsoleweit, überlebt Reconnect, nur recovery_safe-Ops(session.ping, session.status, telemetry.read).

Experiment Engine + Concurrent Lanes

    YAML → Compiler (Validierung, Safe-Number-Policy, Budget) → JCS-RFC8785-IR →Hash → Negotiation → Run → Evidence. Engine läuft auf dem Host.
    In-Flight-RPC: BoundedPool (Token = running+queued, Fix A), Request-IDsREQ-<32hex> eindeutig pro Session, max_inflight serverseitig erzwungen,bounded completed cache, duplicate → PROTOCOL_ERROR.
    Agent-Budget beidseitig: kumulativ Req+Resp-Plaintext, Session- undExperiment-Level (via experiment.load); Überschreitung → atomarer Abort,IN_FLIGHT_AT_ABORT, keine weiteren Responses.

Barrier vs Gate

    Barrier = automatisches Rendezvous (öffnet bei eindeutigen Participants).
    Gate = manuelles Research-Fenster: arrive registriert Participant (unique),released AUSSCHLIESSLICH via sync.gate.release. Destroy → RESOURCE_DESTROYED(nie Success). Participant-Set verhindert Gate-Vorzeitöffnung.
    Alle Sync-Objekte sind ResourceManager-Ressourcen; Cleanup entferntRegistry + zerstört Objekt atomar (B12).

Evidence Flow

Experiment.start → Telemetry/Stage/Primitive/Resource-Events → run_record +stages + inputs/outputs + logs + snapshots + crash/hang + cleanup →Manifest-Hashes → canonical_sha256 (JCS + Safe-Number-Policy) überrun_record. VerificationEvidence wird im Store gespeichert, Re-Hash verifiziert,feldweise gegen den Claim verglichen — erst dann PROVEN.
Exploit Provider / Attack Surface / Candidate

    Provider-Manifest: lifecycle status, requires/provides (verify.*),execution-Kontexte (HOST/WEB_CONTENT/USERLAND_AGENT/... getrennt vonTarget-Kontexten), preconditions, reliability, variants, profile_bindings.
    Surface: reachability chain (PROVEN ⇒ geordnete, eindeutige Kette),Taint-Locators (symbol+offset, keine Roh-Adressen).
    Candidate: state == history[-1].state; ab EXPLOIT_CANDIDATE Pflicht-Reproducer.

Diagramm

Research Host    ↓ps4rfctl    ↓Experiment / Discovery / OrbisProbe    ↓RPC (authentisiert, AEAD, versioniert)    ↓ps4rfd  (heute: Mock ps4rfd)    ↓Userland / Kernel / GPUVM / KeyMgr / CCP / SAMU

SAFETY-AND-EXECUTION-RULES.md
Safety & Execution Rules (normativ)

    Keine Capability als PROVEN ohne VerificationEvidence(Store-Binding, Feldvergleich, Re-Hash, Authority-Ceiling, Run-Separationfür privilegierte Namespaces).
    Keine mutierenden Operationen bei RECOVERY_REQUIRED (zentral erzwingt,nur recovery_safe: session.ping, session.status, telemetry.read).
    Keine stillen Retries nach Hang/Panic/Crash/unexpected state.
    Kein generisches Kernel-Call-RPC (CALL 0x.../PATCH_KERNEL_ADDRESS verboten).
    Kein beliebiges Kernel-Write-RPC — nur registrierte Primitive.
    Firmware-Adressen ausschließlich über Profile; Experimente ohne rohe RVAs.
    Resource Cleanup fail-closed: FREED nur nachweislich; Unsicherheit →UNCERTAIN + console_dirty → RECOVERY_REQUIRED.
    Hang + unsicherer Resource State ⇒ RECOVERY_REQUIRED (konsoleweit).
    Evidence niemals erfinden; kein „PASS" ohne realen Run; Hash-Bindung istPflicht (v0.1 §47).
    Exploit-Ausführung nur nach Safety Gates + Precondition-Checks; keineautomatische Ausführung aus Scanner-Ergebnissen.
    Mock-Hang-Test-Hook ist kein RPC-Element und erzeugt nie eine Response.

FAILS: list[str] = []
CHECKS = 0
SKIP_DIRS = {".git", "venv", ".venv", "__pycache__", ".pytest_cache", "dist"}

def check(cond: bool, msg: str) -> None:
    global CHECKS
    CHECKS += 1
    if not cond:
        FAILS.append(msg)

def read(p: Path) -> str:
    return p.read_text(encoding="utf-8", errors="replace")

def py_files() -> list[Path]:
    return [p for p in ROOT.rglob("*.py") if not SKIP_DIRS & set(p.parts)]

def main() -> int:
    # 1) Python Version
    check(sys.version_info >= (3, 12),
          f"Python >= 3.12 erforderlich, gefunden {sys.version.split()[0]}")
    # 2) Dependencies
    for mod in ("pydantic", "rfc8785", "cryptography", "yaml", "jsonschema", "pytest"):
        try:
            __import__(mod)
        except Exception:
            FAILS.append(f"Dependency fehlt oder defekt: {mod}")
    # 3) Schemas vorhanden und parsebar
    for name in ("common", "capability", "rpc", "evidence", "experiment",
                 "profile", "exploit", "surface", "candidate"):
        p = ROOT / "schemas" / f"{name}.schema.json"
        if not p.exists():
            FAILS.append(f"Schema fehlt: {p}"); continue
        try:
            json.loads(read(p))
        except json.JSONDecodeError as e:
            FAILS.append(f"Schema invalid: {p}: {e}")
    # 4) Freeze-Code-Konsistenz
    pool = ROOT / "core" / "rpc" / "pool.py"
    if pool.exists():
        src = read(pool)
        check(src.count("def submit(") == 1,
              "core/rpc/pool.py: genau eine submit()-Definition erwartet")
        check("if False else" not in src, "pool.py: alte Semaphore-Interna-Zeile noch aktiv")
        check("def available_tokens" in src, "pool.py: available_tokens Test-API fehlt")
    else:
        FAILS.append("core/rpc/pool.py fehlt")
    all_py = "\n".join(read(p) for p in py_files())
    check("_tokens._value" not in all_py, "private Semaphore-Internals im Code/Tests")
    check("PS4RF CORE" not in all_py, "ungültiger Tag-Name 'PS4RF CORE' (Leerzeichen)")
    check("capability_grants_from_runs" not in all_py,
          "alte capability_grants_from_runs Implementierung noch vorhanden")
    hang = [str(p) for p in py_files() if "class MockHangReleased" in read(p)]
    check(hang == [str(ROOT / "core" / "rpc" / "hang.py")],
          f"MockHangReleased exakt einmal in core/rpc/hang.py, gefunden: {hang}")
    mock_src = "\n".join(read(p) for p in (ROOT / "mock").rglob("*.py")) \
        if (ROOT / "mock").exists() else ""
    check('_make_sync_cleanup(""' not in mock_src, "Sync-Cleanup mit leerem Ref")
    check("host_handshake" in mock_src and "agent_handshake(" in mock_src,
          "Mock-Agent nutzt nicht die AGENT-Rolle (agent_handshake)")
    # 5) Gate Runner
    runner = ROOT / "tools" / "freeze" / "run_gate_suite.py"
    if runner.exists():
        rsrc = read(runner)
        check('TAG = "PS4RF-CORE-1.0-MOCK-READY"' in rsrc, "Runner: falscher Tag-Name")
        check('"git", "tag", TAG' in rsrc, "Runner setzt Tag nicht programmatisch")
    else:
        FAILS.append("tools/freeze/run_gate_suite.py fehlt")
    # 6) Capability-Katalog: nur dotted Namespaces
    cat = ROOT / "core" / "capabilities" / "catalog.json"
    if cat.exists():
        try:
            data = json.loads(read(cat))
            names = data if isinstance(data, list) else data.get("capabilities", [])
            pat = re.compile(r"^[a-z][a-z0-9_]*(\.[a-z][a-z0-9_]*)+$")
            bad = [n for n in names if not pat.match(str(n))]
            check(not bad, f"undotted Capability-Namen im Katalog: {bad}")
        except json.JSONDecodeError as e:
            FAILS.append(f"catalog.json invalid: {e}")
    else:
        FAILS.append("core/capabilities/catalog.json fehlt")
    # 7) Operation Registry importierbar
    sys.path.insert(0, str(ROOT))
    try:
        from core.rpc.registry import default_registry  # noqa: F401
        reg = default_registry()
        check(reg.has("session.ping") and reg.has("mock.hang"),
              "Registry: Pflicht-Ops fehlen")
    except Exception as e:
        FAILS.append(f"Registry nicht importierbar: {type(e).__name__}: {e}")
    # 8) Profile-Verzeichnisse
    for fw in ("fw900", "fw1352"):
        check((ROOT / "profiles" / fw).is_dir(), f"profiles/{fw} fehlt")
    # Report
    print(f"PS4RF Pre-Flight: {CHECKS} Checks, {len(FAILS)} Fehler")
    for f in FAILS:
        print(f"  FAIL: {f}")
    print("PRE-FLIGHT: PASS (statisch)" if not FAILS else "PRE-FLIGHT: FAIL")
    return 0 if not FAILS else 1

if __name__ == "__main__":
    sys.exit(main())
