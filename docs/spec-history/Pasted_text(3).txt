1. N1 — Capability Resolution: unabhängige Achsen
1.1 Normativer Algorithmus (ersetzt die gemeinsame Rangfolge aus v0.3)

Auflösung erfolgt pro Tupel (Capability, Scope, Context). Die Achsen werden vollständig getrennt aufgelöst; kein Record der einen Achse beeinflusst die andere.

Availability:
text
 
  
 
 
1. MANUAL availability override              (explizit, wird geloggt)
2. Provider Authority für Availability       (availability_rank aus authority.json,
                                              nur Records mit availability_write)
3. Neuester Runtime-Befund gleicher Authority (Recency innerhalb der höchsten Tier)
4. Recency als letzter Tie-Breaker
→ kein Runtime-Befund: UNKNOWN
 
 

Assurance:
text
 
  
 
 
1. MANUAL darf PROVEN niemals ohne evidence + verified_by (verify.*) setzen
2. Provider Authority Ceiling: effektive Assurance eines Records =
   min(beanspruchte Assurance, max_assurance des Provider-Typs)
3. Rang: PROVEN(evidence+verified_by) > OBSERVED > UNVERIFIED
4. Recency nur zwischen ansonsten gleichwertigen Records
→ Availability fließt strukturell NICHT in die Assurance-Auflösung ein.
 
 

Konsequenzen (normativ):
text
 
  
 
 
PROVEN geht durch späteres UNAVAILABLE niemals verloren — nur der Grant entfällt.
Effective Grant unverändert:
  context match
  AND (availability == AVAILABLE OR (DEGRADED AND allow_degraded))
  AND assurance >= min_assurance
→ PROVEN + UNAVAILABLE = NOT GRANTED, Beleg bleibt erhalten.
 
 

Authority-Tiers für Availability (authority.json, Daten — änderbar ohne Code):
text
 
  
 
 
Tier 100  OPERATOR (MANUAL läuft separat davor)
Tier  30  RUNTIME_PROBE ∪ EXPLOIT   ← gleiche Authority: Recency entscheidet
Tier  20  BOOTSTRAP
Tier  10  MOCK
Tier   0  FIRMWARE_PROFILE (availability_write=false)
 
 

Begründung der Tier-30-Zusammenfassung: EXPLOIT und RUNTIME_PROBE sind beide aktive Session-Befunde. Getrennte Tiers würden den Post-Exploit-Fluss brechen (frischer verifizierter Trigger würde gegen älteren Probe-Befund verlieren) oder Sicherheit brechen (alter Probe-UNAVAILABLE würde frischen Beweis schlagen). Gleiche Tier + Recency erfüllt beide Richtungen. Veto-Punkt.

2. N2 — Handshake und AEAD (verbindlich)
2.1 Key Schedule
text
 
  
 
 
salt            = agent_nonce || host_nonce            (je 128 Bit)
transcript_hash = SHA256( JCS(HELLO) || JCS(HELLO_ACK) )

k_hs            = HKDF-SHA256(secret, salt, "ps4rf/handshake/v1"           || transcript_hash, 32)
k_agent_to_host = HKDF-SHA256(secret, salt, "ps4rf/aead/agent-to-host/v1"  || transcript_hash, 32)
k_host_to_agent = HKDF-SHA256(secret, salt, "ps4rf/aead/host-to-agent/v1"  || transcript_hash, 32)

proof_agent     = HMAC-SHA256(k_hs, "ps4rf/proof/agent/v1" || transcript_hash)
proof_host      = HMAC-SHA256(k_hs, "ps4rf/proof/host/v1"  || transcript_hash)

p_agent_to_host = HKDF-SHA256(secret, salt, "ps4rf/nonce-prefix/agent-to-host/v1" || transcript_hash, 4)
p_host_to_agent = HKDF-SHA256(secret, salt, "ps4rf/nonce-prefix/host-to-agent/v1" || transcript_hash, 4)
 
 

Transcript items (alle über JCS der beiden Nachrichten gebunden): Protokoll-Label (HELLO.label, const), protocol_version, session_id, agent_nonce, host_nonce, target context (HELLO.context), transport (HELLO.transport), AEAD-Suite (HELLO_ACK.aead), provider (HELLO.provider), artifact_sha256 (HELLO.artifact_sha256, falls vorhanden). Suite- oder Context-Manipulation zwischen HELLO_ACK und AUTH ändert daher den transcript_hash → Proof failure.
2.2 Nonce und Sequenz
text
 
  
 
 
Nonce(Richtung) = 32-Bit-Richtungspräfix (HKDF) || 64-Bit-Sequence (Big Endian)
Sequence: strikt monoton; Empfangswert muss exakt dem erwarteten nächsten
Wert entsprechen. Duplicate, Skip, Rückwärts → REPLAY_DETECTED → Session abort.
Sequence Exhaustion (2^64-1 erreicht) → Session schließen, neuer Handshake.
Kein AEAD-Schlüssel wird in Gegenrichtung verwendet (separater HKDF-Info).
 
 
2.3 Schutzphasen
text
 
  
 
 
HELLO / HELLO_ACK   plaintext (enthält keine Sekrete)
AUTH / AUTH_ACK     plaintext, geschützt durch HMAC-Proof an transcript_hash;
                    nur im Zustand HANDSHAKE, einmalig pro Session
READY und alle      AEAD, je Richtung eigener Schlüssel, Sequence ab 0
folgenden
 
 
2.4 rpc-Delta

hello.required += "label"; hello.properties.label = { "const": "ps4rf-handshake-v1" }. message.oneOf enthält auth_ack. Reihenfolge: HELLO → HELLO_ACK → AUTH → AUTH_ACK → READY.
3. N3 — JCS und 64-Bit-Werte (verbindlich)
3.1 Zweischichtiges Modell
text
 
  
 
 
Ebene 1  jcs_bytes(obj)                 reines RFC 8785 (JCS). Referenz für
                                        Golden Vectors inkl. Float-Formate (1e+30).
Ebene 2  canonical_bytes(obj) /         Ebene 1 + PS4RF Safe-Number-Policy.
         canonical_sha256(obj)          Pflicht für: Experiment-Hash, Profil-Hash,
                                        Evidence-Kanonisierung, IR, Options-Hash.
 
 

Safe-Number-Policy (Ebene 2):
text
 
  
 
 
REJECT:  JSON Integer mit |v| > 2^53 - 1
REJECT:  JSON Number mit ganzzahligem Wert und |v| > 2^53 - 1
         (erfasst exponentielle U64-Encodings wie 1.8446744072639246e19;
          nicht-ganzzahlige Floats folgen RFC 8785)
VERBOTEN als JSON Number (schema- und compilereitig):
         Kernel VA, User VA, Pointer, Physical Address, GPU VA,
         vollbreite 64-Bit-Handles, CR3, LSTAR, u64-Identifikatoren
PFlicht: gemeinsame Typen u64_hex / address / address_kernel

9.1 core/canonical.py
python
 
  
 
 
"""Zweischichtiges Canonicalization-Modell (N3)."""
from __future__ import annotations
import hashlib, math
from typing import Any
import rfc8785

SAFE_MAX = 2**53 - 1
SAFE_MIN = -SAFE_MAX

class UnsafeNumber(ValueError):
    """N3: Integer-Semantik oberhalb des interoperabel sicheren Bereichs."""

def validate_safe_numbers(obj: Any) -> None:
    if obj is None or isinstance(obj, (bool, str)):
        return
    if isinstance(obj, int):
        if not (SAFE_MIN <= obj <= SAFE_MAX):
            raise UnsafeNumber(f"Integer außerhalb des sicheren Bereichs: {obj}")
        return
    if isinstance(obj, float):
        # Ganzzahliger Wert oberhalb der Grenze = verlustreiche u64-Encodierung
        if not math.isfinite(obj):
            raise UnsafeNumber(f"Nicht-finite Zahl: {obj!r}")
        if obj.is_integer() and abs(obj) > SAFE_MAX:
            raise UnsafeNumber(f"Float mit Integer-Semantik außerhalb des sicheren Bereichs: {obj!r}")
        return
    if isinstance(obj, dict):
        for k, v in obj.items():
            validate_safe_numbers(k); validate_safe_numbers(v)
        return
    if isinstance(obj, (list, tuple)):
        for v in obj:
            validate_safe_numbers(v)
        return
    raise TypeError(f"Ungültiger JSON-Typ: {type(obj)!r}")

def jcs_bytes(obj: Any) -> bytes:
    """Ebene 1: reines RFC 8785 (Referenz für Golden Vectors, inkl. Floats)."""
    return rfc8785.dumps(obj)

def canonical_bytes(obj: Any) -> bytes:
    """Ebene 2: RFC 8785 + Safe-Number-Policy. Pflicht für alle PS4RF-Hashes."""
    validate_safe_numbers(obj)
    return rfc8785.dumps(obj)

def canonical_sha256(obj: Any) -> str:
    return hashlib.sha256(canonical_bytes(obj)).hexdigest()

def effective_grant(req: Requirement, resolved: Resolution,
                    session_context: TargetExecutionContext,
                    record_context: TargetExecutionContext,
                    authority: AuthorityTable,
                    recovery_required: bool = False) -> GrantDecision:
    ns_min = authority.min_assurance_for_grant.get(
        req.name.split(".")[0], Assurance.UNVERIFIED)
    min_needed = (req.min_assurance
                  if ASSURANCE_RANK[req.min_assurance] >= ASSURANCE_RANK[ns_min]
                  else ns_min)
    if recovery_required:
        return GrantDecision(req.name, False, GrantReason.RECOVERY_REQUIRED,
                             resolved.availability, resolved.assurance)
    if record_context is not session_context:
        return GrantDecision(req.name, False, GrantReason.CONTEXT_MISMATCH,
                             resolved.availability, resolved.assurance)
    avail_ok = (resolved.availability is Availability.AVAILABLE
                or (resolved.availability is Availability.DEGRADED and req.allow_degraded))
    if not avail_ok:
        reason = (GrantReason.DEGRADED_NOT_ALLOWED
                  if resolved.availability is Availability.DEGRADED
                  else GrantReason.CAPABILITY_MISSING)
        return GrantDecision(req.name, False, reason,
                             resolved.availability, resolved.assurance)
    if ASSURANCE_RANK[resolved.assurance] < ASSURANCE_RANK[min_needed]:
        return GrantDecision(req.name, False, GrantReason.ASSURANCE_INSUFFICIENT,
                             resolved.availability, resolved.assurance)
    return GrantDecision(req.name, True, GrantReason.OK,
                         resolved.availability, resolved.assurance)

from __future__ import annotations
import hashlib, hmac, os
from dataclasses import dataclass
from cryptography.exceptions import InvalidTag
from cryptography.hazmat.primitives import hashes
from cryptography.hazmat.primitives.ciphers.aead import AESGCM, ChaCha20Poly1305
from cryptography.hazmat.primitives.kdf.hkdf import HKDF
from core.canonical import canonical_bytes

HANDSHAKE_LABEL = "ps4rf-handshake-v1"
SEQ_MAX = 2**64 - 1

class HandshakeError(Exception): ...
class ReplayDetected(Exception): ...
class SequenceExhausted(Exception): ...

def new_nonce() -> bytes:
    return os.urandom(16)

def transcript_hash(hello: dict, hello_ack: dict) -> bytes:
    """N2: SHA256(JCS(HELLO) || JCS(HELLO_ACK)); Protokoll-Label ist const-Feld
    in HELLO und damit im Transcript gebunden."""
    if hello.get("label") != HANDSHAKE_LABEL:
        raise HandshakeError("HELLO.label fehlt oder falsch")
    return hashlib.sha256(canonical_bytes(hello) + canonical_bytes(hello_ack)).digest()

def _hkdf(ikm: bytes, salt: bytes, info: bytes, length: int = 32) -> bytes:
    return HKDF(algorithm=hashes.SHA256(), length=length, salt=salt, info=info).derive(ikm)

@dataclass(frozen=True)
class HandshakeKeys:
    k_hs: bytes
    k_agent_to_host: bytes
    k_host_to_agent: bytes

def derive_keys(secret: bytes, agent_nonce: bytes, host_nonce: bytes,
                th: bytes) -> HandshakeKeys:
    if len(secret) < 32:
        raise HandshakeError("Session Secret < 256 Bit")
    salt = agent_nonce + host_nonce                    # N2: salt = agent_nonce || host_nonce
    return HandshakeKeys(
        k_hs=_hkdf(secret, salt, b"ps4rf/handshake/v1" + th),
        k_agent_to_host=_hkdf(secret, salt, b"ps4rf/aead/agent-to-host/v1" + th),
        k_host_to_agent=_hkdf(secret, salt, b"ps4rf/aead/host-to-agent/v1" + th))

def nonce_prefix(secret: bytes, agent_nonce: bytes, host_nonce: bytes,
                 th: bytes, direction: str) -> bytes:
    salt = agent_nonce + host_nonce
    return _hkdf(secret, salt, f"ps4rf/nonce-prefix/{direction}/v1".encode() + th, 4)

def proof(k_hs: bytes, role: str, th: bytes) -> bytes:
    return hmac.new(k_hs, f"ps4rf/proof/{role}/v1".encode() + th, hashlib.sha256).digest()

class DirectionChannel:
    """AEAD einer Richtung. Nonce = 4B Präfix || 8B Sequence (BE).
    Empfang muss exakt den erwarteten nächsten Sequenzwert tragen."""
    def __init__(self, key: bytes, prefix: bytes, suite: str = "AEAD_CHACHA20_POLY1305"):
        self._aead = ChaCha20Poly1305(key) if suite == "AEAD_CHACHA20_POLY1305" else AESGCM(key)
        self._prefix = prefix
        self._send = 0
        self._recv = 0

    def _nonce(self, seq: int) -> bytes:
        return self._prefix + seq.to_bytes(8, "big")

    def seal(self, plaintext: bytes, aad: bytes) -> tuple[int, bytes, bytes]:
        if self._send > SEQ_MAX:
            raise SequenceExhausted()
        seq = self._send
        self._send += 1
        return seq, self._nonce(seq), self._aead.encrypt(self._nonce(seq), plaintext, aad)

    def open(self, seq: int, nonce: bytes, ciphertext: bytes, aad: bytes) -> bytes:
        if seq != self._recv:                # Duplicate, Skip, Rückwärts
            raise ReplayDetected(f"seq {seq}, erwartet {self._recv}")
        try:
            pt = self._aead.decrypt(nonce, ciphertext, aad)
        except InvalidTag as e:              # Cross-Direction, Manipulation
            raise HandshakeError("AEAD verify failed") from e
        self._recv += 1
        if self._recv > SEQ_MAX:
            raise SequenceExhausted()
        return pt

class BudgetExceeded(ValueError): ...

def _steps(s):  return s if isinstance(s, list) else []
def _branches(s): return (s.get("branches") or {}).values() if isinstance(s, dict) else ()

def expanded_steps(steps) -> int:
    total = 0
    for s in steps:
        op = s.get("op")
        if op == "REPEAT_BOUNDED":  total += s["count"] * expanded_steps(_steps(s["body"]))
        elif op == "IF":            total += max(expanded_steps(_steps(s.get("then"))),
                                                 expanded_steps(_steps(s.get("else"))))
        elif op == "PARALLEL":      total += sum(expanded_steps(_steps(b)) for b in _branches(s))
        else:                       total += 1
    return total

def max_parallel_tasks(steps) -> int:
    best = 1
    for s in steps:
        op = s.get("op")
        subs = ([_steps(s.get("then")), _steps(s.get("else"))] if op == "IF" else
                _branches(s) if op == "PARALLEL" else
                [_steps(s.get("body"))] if op == "REPEAT_BOUNDED" else [])
        best = max(best, len(list(_branches(s))) if op == "PARALLEL" else 1,
                   *(max_parallel_tasks(b) for b in subs))
    return best

def nesting_depth(steps, d: int = 1) -> int:
    best = d
    for s in steps:
        op = s.get("op")
        subs = ([_steps(s.get("then")), _steps(s.get("else"))] if op == "IF" else
                _branches(s) if op == "PARALLEL" else
                [_steps(s.get("body"))] if op == "REPEAT_BOUNDED" else [])
        for b in subs:
            best = max(best, nesting_depth(b, d + 1))
    return best

def runtime_bound_ms(steps, default_step_ms: int) -> int:
    total = 0
    for s in steps:
        op = s.get("op")
        if op == "REPEAT_BOUNDED":  total += s["count"] * runtime_bound_ms(_steps(s["body"]), default_step_ms)
        elif op == "IF":            total += max(runtime_bound_ms(_steps(s.get("then")), default_step_ms),
                                                 runtime_bound_ms(_steps(s.get("else")), default_step_ms))
        elif op == "PARALLEL":      total += max(runtime_bound_ms(b, default_step_ms) for b in _branches(s))
        elif op == "SLEEP_BOUNDED": total += s["ms"]
        elif op == "WAIT_BARRIER":  total += s.get("timeout_ms", default_step_ms)
        else:                       total += default_step_ms
    return total

def check_budget(ir: dict) -> dict:
    computed = {
        "max_expanded_steps": expanded_steps(ir["steps"]),
        "max_parallel_tasks": max_parallel_tasks(ir["steps"]),
        "max_nesting_depth": nesting_depth(ir["steps"]),
        "max_runtime_budget_ms": runtime_bound_ms(ir["steps"], ir["timeouts"]["default_step_ms"]),
        "max_snapshot_bytes": sum(r["explicit"]["size"] for s in ir["steps"]
                                  if s.get("op") == "SNAPSHOT"
                                  for r in s.get("targets", []) if "explicit" in r) or 1,
        "max_rpc_bytes": CAPS["max_rpc_bytes"],
    }
    declared = ir.get("budget", {})
    for k, cap in CAPS.items():
        v = computed[k]
        if v > cap or (k in declared and v > declared[k]):
            raise BudgetExceeded(f"{k}: computed={v}, cap={cap}, declared={declared.get(k)}")
    return computed

def redact_options(options: dict, extra_fields: list[str] | None = None) -> tuple[dict, list[str]]:
    extra = set(extra_fields or ())

def _mini_jcs(obj) -> bytes:
    """Unabhängige JCS-Referenz (Strings/Ints/Bool/None/Container).
    Sortierung nach UTF-16-Code-Units, ES6-String-Escaping."""
    if obj is None:  return b"null"
    if obj is True:  return b"true"
    if obj is False: return b"false"
    if isinstance(obj, int): return str(obj).encode()
    if isinstance(obj, str):
        return json.dumps(obj, ensure_ascii=False,
                          separators=(",", ":")).encode("utf-8")
    if isinstance(obj, list):
        return b"[" + b",".join(_mini_jcs(v) for v in obj) + b"]"
    if isinstance(obj, dict):
        items = sorted(obj.items(), key=lambda kv: kv[0].encode("utf-16-be"))
        return (b"{" + b",".join(_mini_jcs(k) + b":" + _mini_jcs(v)
                                 for k, v in items) + b"}")
    raise TypeError
